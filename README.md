# OpenCart Manual Testing Documentation

This repository contains the complete manual software testing artifacts and defect management documentation for the OpenCart e-commerce platform.

---

## Deliverables and Artifacts

* **Test Cases Documentation (`Final Test case (open cart ).xlsx`):** A comprehensive suite of functional and user interface test cases covering core user flows, boundary value analysis, and equivalence partitioning.
* **Defect Log and Bug Report (`Final Bug Report( Open Cart ) .xlsx`):** A detailed repository of discovered issues during the testing lifecycle, documented with strict metrics including severity, priority, steps to reproduce, and environmental details.

---

## Testing Scope and Coverage
The manual execution phase targeted the following core components of the application:
* User Authentication (Registration, Login, and Session Management).
* Catalog Navigation (Product Search, filtering, and category sorting).
* Cart Operations (Adding/Removing items and dynamic subtotal calculations).
* Checkout Pipeline (Form validation, shipping/billing selection, and order finalization).

---

## Methodology
The testing cycle adhered to standard Software Testing Life Cycle (STLC) practices:
1. **Requirements Analysis:** Reviewing standard e-commerce workflows to derive testing scenarios.
2. **Test Design:** Developing highly detailed test cases with explicit preconditions, input data, and expected results.
3. **Test Execution:** Manual verification across multiple desktop and mobile viewports.
4. **Defect Reporting:** Logging behaviors that deviated from expected outcomes to streamline the remediation process for development teams.
